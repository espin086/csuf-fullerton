For authorized repository users

Run your first command.

This template repository is currently private. With repository access and Python 3.11 or later:

git clone https://github.com/espin086/template-python-cli.git
cd project-template
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
project-template hello world

On Windows, activate with .venv\Scripts\activate. See the README for development setup.
